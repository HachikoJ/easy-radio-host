Demo text is original sample copy.

The rotating disc and surrounding motion draw on common interactions seen in NetEase Cloud Music and other players. Tingjian independently implements the geometry, styling, and shaders for the disc, black ring, colorful glowing edges, and translucent 3D waves without copying their code, branding, visual skins, or media assets, and without implying affiliation or endorsement. User-provided reference imagery informs the spatial design and is not redistributed. The disc center uses attributed theme photography, not the track's actual album artwork. Where the browser and audio source support it, native captureStream and a separate Web Audio analysis branch measure frequency bands, bass, and volume. Smooth playback animation is used when analysis is unavailable, with 2D ripples available without WebGL. Native audio output is preserved, and a real-time spectrum is not claimed on every device.
